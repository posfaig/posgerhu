Privacy Policy

Last updated: 9 November 2026

This policy covers a private, single-user personal automation project operated by Gergely Pósfai, Budapest, Hungary.

The project accesses Google user data from the operator's own Google Account only, after explicit consent granted through Google's OAuth 2.0 flow, and only through read-only scopes.

That data is used solely to provide the project's features to the operator. It is stored only on the operator's own device, is not shared with any third party, and is not used for advertising or to train machine-learning models.

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the stored credentials.
